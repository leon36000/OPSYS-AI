# ADR proposé — équipes indépendantes et ownership explicite

Status: PROPOSED_FROM_NATHAN_CURRENT_DIRECTIVE

## Décision

- GitHub est la source mutable partagée.
- Codex avance le Core C00–C24.
- Claude Code traite les issues et l'assainissement transversal.
- Exactement un owner par mission.
- Aucune plateforme n'est maître de l'autre.
- Une mise au point courte environ toutes les 24 heures suffit.
- La review croisée est facultative et ciblée.

## Supersession

Cette décision remplace opérationnellement l'ancien modèle où Claude Code était maître d'œuvre GitHub global.

## Conséquences

- moins de coordination;
- queues distinctes;
- branches/worktrees distincts;
- autonomie dans le scope;
- gates proportionnés;
- aucun code métier M avant le handoff Core.

La décision doit être enregistrée dans le canon GitHub lors de la prochaine mise à jour autorisée.
