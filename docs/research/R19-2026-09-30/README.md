dans [MANIFEST.json](MANIFEST.json). Les archives utilisent gzip déterministe (`mtime=0`) et ont été

pas les ajouts ultérieurs ni les tests du produit.

extraits vers des chemins distincts, avec leur [provenance de récupération](preuves/archive-controle/r19-installateur-source-recovery.json.gz)
